Текстовый гайд :
1. Скачать два файла
2. Переместить сам тест с расширением exe в папку с нашими (моими) двумя файликами 
3. Запустить bat файл
4. После открытия, создастся пропатченный клон-файл теста, именно он нам и нужен
Запускаем его, проходим как попало и получаем хорошую оценку 
Тест можно завершить досрочно при желании более скрытной от подозрения оценки и получить 4 или 3
